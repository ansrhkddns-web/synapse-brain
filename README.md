# SYNAPSE BRAIN

Claude·코덱스(GPT) 같은 AI 에이전트를 **부서처럼** 굴리는 개인용 AI 관제실이자 세컨드브레인.

- 모든 기억은 `vault/` 아래 마크다운 파일입니다. `[[링크]]`, 백링크, 그래프, 태그, 템플릿, 날짜별 일지가 있어 옵시디언 볼트로도 그대로 열립니다.
- 이 PC에서 도는 **Claude Code 세션과 코덱스 대화·호출을 자동으로 작업 기록**으로 남기고, 연 폴더와 말을 보고 부서에 배정합니다. 노트를 따로 쓰지 않아도 쌓입니다.
- 화면(http://127.0.0.1:4747)에서 일을 시키면 부서 세션이 일하고, 고를 것은 결정 카드로, 끝난 일은 검수로 올라옵니다. 완료는 사람만 찍습니다.
- 일하다 알게 된 것(배움)이 모이면 "스킬로 만들까요?" 결재가 올라오고, 스킬관리부가 Claude 스킬로 만들어 다른 작업에서 다시 씁니다.
- 기억에 질문하기(근거 문서를 달아 답함), 기억 정리(층·무게), 공정 실행기, PC 사용량·토큰 사용량, 멈춤 감지, 휴대폰 알림.

이 저장소는 **순정판**입니다. 코드·화면·규칙·틀·예시만 있고, 원래 PC의 작업·결정·보고서·기억·결과물은 들어 있지 않습니다.

## 이렇게 씁니다

1. 평소처럼 Claude Code나 Codex에서 일하거나, 관제실에서 부서에 작업을 맡깁니다.
2. 작업 진행과 결과를 부서별로 확인합니다. AI가 판단을 요청하면 결정 카드에서 답합니다.
3. 결과를 검수하고 완료 처리합니다. 다시 찾아볼 기록은 보관함의 마크다운 파일로 남습니다.

## 설치

Windows 10/11 x64, Node.js 22 이상, Claude 계정이 필요합니다. 코덱스(ChatGPT 계정)는 선택입니다.

Claude Code에게 이렇게 말하면 됩니다.

> INSTALL.md를 읽고 SYNAPSE BRAIN을 설치해 줘

직접 하려면 [INSTALL.md](INSTALL.md)를 순서대로 따릅니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `app/` | 두뇌 서버(Node), 화면(`web/`, 빌드본 `web/dist` 포함), 스크립트, 테스트, 윈도우 트레이 프로그램 소스(`desktop/`). 구조와 API는 `app/README.md` |
| `vault/` | 빈 보관함: 공통 규칙, 틀, 기본 부서 6개 |
| `예시/` | 다른 부서 규칙 예시(영상편집·번역·웹앱 운영·경영지원실)와 한국 사업자용 세무달력 예시 |
| `부서작업/` | 부서가 만든 결과물이 쌓이는 곳 |

## AI 연결 한눈에

| AI | 하는 일 | 연결 |
|---|---|---|
| Claude (Agent SDK) | 화면에서 시킨 일을 부서 세션으로 실행 | `claude.exe auth login` 한 번 (INSTALL 4절) |
| Claude Code (데스크톱·터미널) | 내가 직접 연 세션을 작업으로 자동 기록, 화면에서 멈추기·지시 잇기 | `node app/scripts/hooks.mjs install` (INSTALL 6절) |
| 코덱스 (GPT) | 코덱스 대화는 작업 하나씩, 다른 프로그램이 부른 호출은 날짜·폴더별로 묶어 기록 | 코덱스 앱이나 CLI에 ChatGPT 계정으로 로그인만 하면 됨. 서버가 `~/.codex/sessions`를 30초마다 읽음 |
| 그 밖의 AI 프로그램 (ollama·ComfyUI·python 등) | CPU·RAM·GPU 몫을 세션·부서에 붙여 보여 줌 | 따로 할 것 없음 |
