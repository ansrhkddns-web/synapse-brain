# SYNAPSE BRAIN

**Claude와 Codex로 한 일을 기록하고, 다음 작업에 다시 쓰는 Windows용 개인 AI 관제실.**

평소처럼 Claude Code나 Codex에서 일하면 로컬 세션 기록을 작업으로 정리합니다. 관제실에서 새 작업을 부서에 맡기고, AI가 판단을 요청하면 결정 카드에서 답합니다. 결과를 검수하고 완료하는 건 사람의 몫입니다.

기록은 `vault/`의 마크다운 파일로 저장됩니다. SYNAPSE BRAIN에서 검색하거나, 같은 폴더를 Obsidian 볼트로 열어 읽고 편집할 수 있습니다.

## 처음 시작하기

Windows 10/11 x64, Node.js 22 이상, Claude 계정이 필요합니다. Codex 연동은 선택입니다.

1. 저장소를 내려받습니다.

   ```powershell
   git clone https://github.com/ansrhkddns-web/synapse-brain.git
   ```

2. 받은 폴더에서 Claude Code에 **“INSTALL.md를 읽고 SYNAPSE BRAIN을 설치해 줘”**라고 요청하거나 [설치 안내](INSTALL.md)를 직접 따릅니다.
3. 설치를 마치면 [이 PC의 관제실](http://127.0.0.1:4747)을 엽니다. 먼저 작은 작업을 비서실에 맡겨 진행부터 검수까지 확인해 보세요.

이 저장소는 **순정 배포본**입니다. 기본 부서 6개, 규칙, 템플릿, 예시와 빌드된 화면을 제공합니다. 기존 사용자의 개인 작업·결정·보고서·기억·결과물은 포함하지 않습니다.

## 화면에서 할 수 있는 일

| 화면 | 할 수 있는 일 |
| --- | --- |
| 데스크 | 실행 중인 세션, 새 답변, 내가 결정하거나 검수할 일을 확인합니다. |
| 지도 | 관제실 → 부서 → 하위 항목 → 작업 구조와 현재 실행 중인 세션을 봅니다. |
| 보드·기록 | 결정 대기, 실행 중, 예약, 검수 상태를 보드에서 보고, 진행 내역은 시간순으로 읽습니다. |
| 기억 | 작업·결정·보고서를 위키링크와 백링크로 탐색합니다. 그래프는 문서 종류·부서·태그로 거를 수 있고, `Ctrl+K`로 전체 검색을 열 수 있습니다. |

작업·결정·보고서·일지·공정은 템플릿으로 작성합니다. **기억에 질문하기**는 보관함과 연결된 참고 문서를 읽어 근거 링크와 함께 답합니다. **기억 정리**에서는 기록을 지금·기준·결과·흔적으로 나눠 보고, 어떤 기록이 필요한지 판단한 이유를 확인할 수 있습니다.

반복 업무는 **공정 실행기**에서 단계별로 실행하고 필요한 단계에서 승인을 받을 수 있습니다. 작업 중 발견한 방법과 주의점은 **배움**에 모아 두고, 제안을 승인하면 Claude 스킬 제작 작업으로 넘깁니다. **일정비서**는 보관함의 할 일을 오늘 기준으로 정리하며, Asana나 Slack 같은 외부 항목을 모으려면 별도 연결과 예약 작업 설정이 필요합니다.

## AI 연결과 기록 범위

| 연결 | 하는 일 | 설정 |
| --- | --- | --- |
| Claude Agent SDK | 관제실에서 맡긴 일을 부서 세션으로 실행합니다. | [설치 안내 4절](INSTALL.md#4-claude-로그인-sdk용-한-번)의 SDK용 로그인 |
| Claude Code 데스크톱·터미널 | 직접 연 세션을 작업으로 기록합니다. 연결된 세션은 관제실에서 멈추거나 지시를 이을 수 있습니다. | [설치 안내 6절](INSTALL.md#6-ai-연결)의 전역 훅 설정 |
| Codex 앱·CLI | 로컬 대화는 작업별로, 자동 호출은 날짜·작업 폴더별로 기록합니다. 대화의 마지막 답변을 검수할 수 있습니다. | 같은 PC에서 Codex에 로그인하면 서버가 로컬 세션 파일을 주기적으로 읽습니다. |

웹이나 모바일 ChatGPT에만 남은 대화는 자동으로 가져오지 않습니다. 관제실의 대화 원문 탭은 현재 Claude 세션을 지원합니다. Windows 사용량 계기판은 CPU·RAM·GPU와 Claude 토큰 사용량을 보여주며, 휴대폰 알림은 별도 설정 후 사용할 수 있습니다.
