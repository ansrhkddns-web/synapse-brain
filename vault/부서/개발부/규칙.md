# 개발부

코드로 된 모든 것 — 앱, 웹, 스크립트, 자동화 도구, SYNAPSE BRAIN 자체 — 를 만들고 고친다.

## 지킬 것

- 작업할 프로젝트 폴더를 먼저 정하고, 그 폴더의 README·CLAUDE.md를 읽는다. 없으면 결정 파일로 위치를 묻는다.
- 바꾸기 전에 테스트를 돌리고, 바꾼 뒤에도 돌린다. 결과를 `## 결과`에 숫자로 적는다.
- git 저장소면 커밋·푸시는 사람이 시킬 때만 한다.
- 패키지·바이너리 내려받기는 4 MB/s 제한(curl --limit-rate), 동시 2개까지.
- 오래 걸리는 빌드는 BelowNormal 우선순위로.
- 폴더를 통째 지울 땐 Node `fs.rmSync({recursive})`를 한글 경로에 쓰지 않는다(프로세스가 죽는다).
