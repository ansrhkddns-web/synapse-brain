# 스킬관리부

사용자가 Claude로 하는 모든 일(이 PC의 Claude Code 세션 전부)을 모아, **여러 번 되풀이되는 일을 스킬로 만든다.** 만든 스킬은 다듬어서 **명칭과 기능**을 정확히 적고, 전부 하위 항목 「스킬보드」(처음 보드를 만들 때 save_unit으로 만든다)에 올려 한눈에 보게 한다.

## 하위 항목

| 하위 | 하는 일 |
|---|---|
| 스킬수집 | 대화 기록에서 한 일을 모으고 스킬 후보를 뽑는다 |
| 하위 항목 「스킬보드」(처음 보드를 만들 때 save_unit으로 만든다) | 스킬 목록(정본 `skills.json`)과 그 목록을 보여 주는 아티팩트 보드 |

## 일하는 순서

1. **수집**: `node "{{BRAIN}}\app\scripts\skill-harvest.mjs"` → `스킬수집\actions-YYYY-MM-DD.json`·`.md`. 세션마다 자리(부서·하위), 사람 말, 쓴 도구·스킬·커넥터·게시 수가 들어 있다. 바깥 세션 작업 기록(`vault/작업`의 태그 `바깥세션`)도 같은 재료다.
   - **배움**(`vault/기억/배움-YYYY-MM-DD.md`)도 재료다. 두뇌 세션이 일하다 남긴 것(`note_learning`), 평일 18:30 그날 기록에서 뽑은 것, 사람이 기억 탭 「배움」에서 적은 것이 쌓인다. 같은 일에 대한 배움이 모이면 서버가 「스킬로 만들까요?」 결재를 올리고, 사람이 고르면 **「스킬 만들기·고치기 · <name>」 작업**이 이 부서로 온다 — 그 지시(근거 배움·들어갈 내용)대로 아래 3~5를 한다.
2. **후보 뽑기**: 사람 말을 다 읽고, **2개 이상 세션에 나온 같은 절차**(또는 한 세션에서 오래 되풀이된 절차)를 후보로 적는다 → `스킬수집\candidates-YYYY-MM-DD.json`. 한 번뿐인 대화, 커넥터 하나 부르면 끝나는 일은 후보가 아니다.
3. **스킬로 만들기**: 값이 큰 후보부터 `{{HOME}}\.claude\skills\<name>\SKILL.md`로 쓴다(스킬 `skill-creator`의 방식). `description`에는 **무엇을 하는지 + 사용자가 실제로 쓰는 호출 말**을 넣는다. 실제 세션에서 해 온 단계·경로·주의점을 본문에 적는다.
4. **다듬기**: 다음 수집 때 그 스킬이 불렸는지, 불렸는데 사람이 고쳐 말한 곳이 있는지 보고 SKILL.md를 고친다. 고친 날과 이유를 보드의 `history`에 남긴다.
5. **보드 갱신**: `스킬보드\skills.json`을 고치고 보드 아티팩트에 **`skills.json`만** 다시 게시한다(아래 「보드 게시」).

## 스킬 상태

| 상태 | 뜻 |
|---|---|
| `운영중` | SKILL.md가 있고 실제로 불린다 |
| `다듬는중` | SKILL.md를 만들었거나 고치는 중, 아직 실제 호출로 확인 안 됨 |
| `후보` | 되풀이가 보였지만 아직 스킬이 없다 |
| `보류` | 만들지 않기로 함(사람이 정함) |

출처: `개인`(`~/.claude/skills`), `조직`(anthropic-skills:… 등 조직 배포 — **고치지 않는다**, 고칠 점만 보드에 적는다), `플러그인`, `기본`.

## 보드 게시

- 보드: 하위 항목 「스킬보드」(처음 보드를 만들 때 save_unit으로 만든다) 문서의 주소. 새 아티팩트를 만들지 않는다.
- 게시 전에 보드를 읽고(Artifact `read`), `files`에 `skills.json`만 넣어 같은 주소로 게시한다. 페이지(`index.html`)를 고칠 때만 페이지도 함께.
- `skills.json`은 `{updated, skills:[…]}`. 스킬 하나: `name`, `title`(한글 명칭), `function`(기능 한 문장), `status`, `source`, `path`, `dept`, `unit`, `triggers`, `steps`, `inputs`, `outputs`, `tools`, `sessions`(쓰인·나온 세션 수), `lastUsed`, `evidence`, `note`, `history`.

## 지킬 것

- 사람 말을 옮길 때 60자 안쪽으로 줄이고, 키·토큰·비밀번호처럼 보이는 것은 옮기지 않는다.
- 임직원 연봉·임금 정보는 스킬·보드에 쓰지 않는다.
- 대외비 문서 내용은 스킬 본문에 옮기지 않는다. 경로와 절차만 적는다.
- 다른 부서의 작업 폴더 파일은 고치지 않는다. 스킬이 그 부서 일이면 그 부서 하위 문서에 "이 스킬을 쓴다"는 줄만 더하도록 그 부서 앞으로 작업을 만든다.
