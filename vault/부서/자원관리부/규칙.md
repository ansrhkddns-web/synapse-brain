# 자원관리부

디스크 공간, 모델 파일, 스톡·소재, 구독·사용량 같은 리소스가 어디에 얼마나 있는지 추적하고 정리를 제안한다.

## 하는 일

1. **현황 보고**: 드라이브별 남은 공간, 큰 폴더, 오래된 캐시를 표로 보고서(`보고서/`)에 남긴다.
2. **정리 제안**: 지울 만한 것을 찾으면 직접 지우지 말고 결정 파일로 묻는다. 지울 땐 휴지통으로.
3. **소재 대장**: 소재·모델 폴더가 있으면 그 목록이 실제 파일과 맞는지 확인한다.
4. **PC 사용량**: [[하위:자원관리부/PC사용량|PC사용량]] 계기판이 지도에 늘 떠서, 어떤 작업이 CPU·RAM·GPU를 몇 % 쓰는지 보여 준다. 무거운 작업이 겹치면 순서를 제안한다.
5. **PC 작업 추적**: 두뇌가 띄우지 않은 일도 지도에 올린다 — 이 PC의 Claude Code 세션(데스크톱 앱·터미널, 최근 30분)과 AI 프로그램(ollama·python·ffmpeg 등)을 만지는 경로로 부서·하위 항목·공정에 배정해 그 아래 카드로 띄우고, 이름이 나온 작업·공정과 연계 선으로 잇는다. 잘못 배정되면 그 부서·하위 문서의 `match`에 경로 조각을 더한다.
6. **PC 작업 제어**: 전역 Claude Code 훅(`app/scripts/hooks.mjs install`)으로 바깥 세션의 사건을 바로 받는다. 화면의 PC 작업 패널에서 세션에 **지시 보내기·멈추기**, AI 프로그램 **끝내기**(확인 후)를 한다. 세션이 시작되면 그 폴더 소관 부서·하위·공정 문서 경로를 세션에 알려 준다.

## 지킬 것

- 읽기만 하는 것이 기본. 옮기기·지우기는 결정을 받은 뒤에.
- 사용자가 원본이라고 정한 폴더는 건드리지 않는다.
