# PC사용량

지도 화면의 자원관리부 가지에 늘 붙어 있는 **사용량 계기판**이다. 계기판을 누르면 오른쪽 패널에 자세한 값이 뜬다.

## 보이는 것

| 칸 | 뜻 |
|---|---|
| CPU | PC 전체 CPU 사용률 (모든 코어 합 기준) |
| RAM | 쓰는 메모리 / 전체 메모리 |
| GPU · VRAM | NVIDIA GPU 사용률·온도, 그래픽 메모리 (nvidia-smi) |
| 작업 세션 | 지금 도는 SYNAPSE BRAIN 작업마다 CPU·RAM·GPU·VRAM 몫. 세션 프로세스와 그 세션이 띄운 자식 프로그램(ffmpeg·python 등)까지 합쳐 센다 |
| 무거운 프로그램 | 세션 밖에서 도는 프로그램을 이름으로 묶어(chrome ×54 처럼) 가장 무거운 것부터 |

지도의 실행 중 작업 카드 오른쪽 위에도 그 작업의 몫이 뜬다. 85% 를 넘는 값은 노란색으로 표시된다.

## 어떻게 재나

- 서버의 `app/lib/monitor.mjs`가 `app/scripts/usage.ps1`을 **낮은 우선순위(BelowNormal)**로 띄워 4초마다 잰다.
- 누가 화면(지도의 계기판, 사용량 패널)을 보고 있을 때만 돌고, 1분 동안 아무도 안 보면 저절로 꺼진다.
- 프로세스별 값은 Windows 성능 카운터(프로세스 CPU·전용 메모리, GPU 엔진·GPU 프로세스 메모리), 전체 GPU 값은 `nvidia-smi`.
- API: `GET /api/usage`.

## 쓰는 법

- GPU 작업(TTS 녹음, 받아 적기, GPU 렌더)을 시작하기 전에 GPU·VRAM이 비었는지 여기서 본다. GPU 작업은 한 번에 하나씩 돌린다.
- 오래 걸리는 작업이 PC를 다 차지하면(CPU·RAM 85% 넘음) 그 작업 카드를 열어 멈추거나 우선순위를 낮춘다.
