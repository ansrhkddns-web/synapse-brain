# 관제실

SYNAPSE BRAIN의 한가운데(관제실). 모든 부서가 관제실 아래에 있고, 부서 → 하위 항목 → 작업·참고 폴더 → 문서로 지식이 퍼져 나간다. 지도에서는 이 점이 가운데에 고정되고, 단계가 깊어질수록 점이 작아지며 바깥 고리로 퍼진다.

## 거느리는 부서

- [[부서:비서실|01 비서실]] — 지시를 부서로 나누고 하루를 정리
- [[부서:개발부|02 개발부]] — 코드·앱·웹·자동화 도구
- [[부서:리서치부|04 리서치부]] — 조사·비교·트렌드 보고서
- [[부서:스킬관리부|05 스킬관리부]] — Claude로 한 일을 모아 스킬로 만들고 스킬 보드를 관리
- [[부서:자원관리부|97 자원관리부]] — 리소스 관리, PC 사용량·PC 작업 추적
- [[부서:비정규직|99 비정규직]] — 어디에도 딱 맞지 않는 잡일

부서를 더하거나 빼면 이 목록도 고친다.

## 지식이 이어지는 방식

- 부서의 작업 폴더(`workdir`)에 있는 md 문서와 폴더는 **참고 문서**로 지도에 붙는다(읽기 전용).
- 하위 항목 문서가 적은 경로(엔진·문서·결과물 폴더)는 그 하위 항목 아래로 옮겨 달리고, 문서끼리 서로 적은 경로는 시냅스 선으로 이어진다.
