# 부서작업 — SYNAPSE BRAIN 부서가 만든 결과물 폴더

SYNAPSE BRAIN 부서가 일하면서 **새로 만드는** 프로젝트·결과물은 모두 이 폴더 아래에 둔다. 작업 루트(`{{WORK}}`) 바로 아래에 새 폴더를 만들지 않는다.

## 규칙

```
부서작업\<부서 이름>\<하위 항목 이름>\
```

1. **부서 이름**은 `vault\부서\` 폴더 이름과 똑같이 쓴다.
2. **하위 항목 이름**은 `vault\부서\<부서>\하위\<이름>.md`와 똑같이 쓰고, 그 하위 문서의 `workdir`가 이 폴더를 가리키게 한다. 이름이 같아야 PC 작업 추적이 그 자리 일로 가린다.
3. 하위 항목이 아직 없으면 폴더를 만들 때 하위 항목도 함께 만든다 (`mcp__brain__save_unit`).
4. 여러 부서가 같이 쓰는 결과물은 **결과물을 내는 부서** 아래에 둔다.
5. 부서 안에 하위 단위가 있는 부서는 그 구조를 따른다 (예: 경영지원실은 `<회사 이름>\<하위 부서>\`).

## 바깥에 그대로 두는 것

SYNAPSE BRAIN 전부터 따로 있던 독립 프로젝트는 옮기지 않는다. 부서·하위 문서의 `workdir`가 그 자리를 가리키게 하고, 아래 표에 적는다.
