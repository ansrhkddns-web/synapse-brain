# 세무 기준표 — <회사 이름> (재경부)

> 기준일 2026-11-01. **확인됨** = 공식 사이트나 여러 보도로 확인, **법령 기준** = 조문 내용(쓰기 전에 링크로 원문 확인), **미정** = 아직 확정 안 됨.
> 마감 일정은 지도의 재경부 아래 **세무달력** 카드(자료 `세무달력.yaml`)에서 본다. 이 표는 "얼마·몇 %·누가 해당하나"를 정리한다.

## 1. 회사 유형에 따라 갈리는 것

| 구분 | 기준 | 상태 |
|---|---|---|
| 간이과세자 | 직전 연도 공급대가 **1억 400만 원 미만**(2026). 넘으면 다음 해 7월 1일부터 일반과세 | 확인됨 (2027 기준 변경은 미정) |
| 간이과세자 세금계산서 발급 | 직전 연도 공급대가 **4,800만 원 이상**이면 발급 의무, 미만·신규는 영수증 | 법령 기준 — [부가가치세법 제36조](https://www.law.go.kr/법령/부가가치세법/제36조) |
| 간이과세자 납부 면제 | 공급대가 4,800만 원 미만이면 납부 의무 면제(신고는 함) | 법령 기준 |
| 부가세 과세·면세 | 기획사의 매니지먼트, 음원·영상 제작·판매는 **과세**. 연예인 개인이 직원·물적시설 없이 직접 하는 인적용역은 **면세** | 법령 기준 — [부가가치세법 시행령 제42조](https://www.law.go.kr/법령/부가가치세법시행령/제42조) |
| 복식부기의무자 (직전 연도 수입금액) | 가군 3억 / 나군 1억 5천만(정보통신업 — 음반·영상 제작 가능성) / **다군 7,500만**(예술·스포츠·여가 서비스업 — 매니지먼트 가능성) | 확인됨 — [국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2230&cntntsId=7669) |
| 성실신고확인 대상 | 가군 15억 / 나군 7.5억 / 다군 5억 | 법령 기준 — 소득세법 시행령 제133조 |
| 사업용계좌 | 복식부기의무자는 과세기간 시작일부터 6개월 안에 신고. 바꾸거나 추가하면 종합소득세 신고기한까지 | 확인됨 — [국세청 상담센터](https://call.nts.go.kr/call/qna/selectQnaInfo.do?mi=1441&ctgId=CTG11781) |
| 현금영수증 의무발행 업종 | 2026년 142개 업종. 매니지먼트·음반 제작이 들어 있는지는 주업종 코드로 확인 필요. 해당하면 10만 원 이상 현금거래 때 발급 의무, 안 하면 가산세 20% | 미정 (업종 코드 확정 후) |

> **먼저 정할 것**: 사업자등록의 **주업종 코드**. 매니지먼트(다군)인지 음반·영상 제작(나군)인지에 따라 복식부기·성실신고 기준과 현금영수증 의무가 달라진다.

## 2. 돈을 줄 때 떼는 세금 (원천징수)

| 지급 | 떼는 세금 | 신고·납부 | 상태 |
|---|---|---|---|
| 직원 급여 | 근로소득 간이세액표(소득세법 시행령 별표 2) — 홈택스 "근로소득 간이세액표" 조회 | 다음 달 10일 원천세 | 법령 기준 |
| 프리랜서(사업소득, 인적용역) | **3% + 지방소득세 0.3% = 3.3%** | 다음 달 10일 원천세 + 다음 달 말일 간이지급명세서 | 법령 기준 — 소득세법 제129조 |
| ↳ 2027 개편안 | 3% → **2%**(지방세 포함 2.2%), 2027-01-01 지급분부터 적용하는 안 | 미정 (국회 심의 중, [택스워치](https://www.taxwatch.co.kr/article/tax/2026/08/05/0004)) |
| 일시적 출연·강연 (기타소득) | 필요경비 60% 뒤 20% → 실효 **8.8%** | 다음 달 10일 원천세 + 간이지급명세서 | 법령 기준 — 소득세법 제129조, 시행령 제87조 |
| 기타소득 과세최저한 | 건별 기타소득금액 5만 원 이하면 과세 안 함 → 필요경비 60% 적용 시 지급액 **12만 5천 원 이하** | — | 법령 기준 — [소득세법 제84조](https://www.law.go.kr/법령/소득세법/제84조) |
